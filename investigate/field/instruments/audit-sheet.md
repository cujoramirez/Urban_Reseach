# Sidewalk Audit Sheet (per segment)

A printable template for scoring one **segment** of street (one block / one side, by named
street). Print one copy per segment, or replicate the table into the audit CSV
(see [`../data/README.md`](../data/README.md)).

## Segment identification

- **Segment ID:** ________  (e.g. `SUD-N-03` = Sudirman, north side, segment 3)
- **Named street:** ____________________________
- **Side of street:** ☐ N / E   ☐ S / W
- **Date / time:** ____________________________
- **Auditor(s):** ____________________________
- **GPS pin (lat, long):** ____________________________
- **Photo reference(s):** ____________________________  (filenames / external link)
- **Day or night audit:** ☐ Day   ☐ Night

## Scoring

Score each parameter **0–2**:
**0 = absent / poor**, **1 = partial / acceptable**, **2 = present / good**.
Use **N/A** only where a parameter genuinely does not apply.

| # | Parameter | 0 | 1 | 2 | Notes |
|---|-----------|---|---|---|-------|
| 1 | **Sidewalk present** (is there a sidewalk at all?) | ☐ | ☐ | ☐ | |
| 2 | **Effective width ≥ 1.5 m** (clear walkable width, after obstructions) | ☐ | ☐ | ☐ | |
| 3 | **Surface intact** (no holes, broken tiles, trip hazards) | ☐ | ☐ | ☐ | |
| 4 | **Obstruction** (0 = heavily blocked, 2 = clear) — note type below | ☐ | ☐ | ☐ | type: |

| 9 | **Shade** (trees, canopy, shelter from sun/rain) | ☐ | ☐ | ☐ | |
| 10 | **Drainage / open gutter** (0 = open/dangerous gutter, 2 = covered/safe) | ☐ | ☐ | ☐ | |
