# Transcripts

Transcripts of **street intercepts** and the **policy-expert interview**.

## ⚠️ Consent before recording

- Get **explicit verbal consent to record** *before* you start any audio recording, this is
  separate from consent to participate. See the
  [intercept script](../instruments/intercept-script.md).
- If someone declines recording, you may still take written notes (if they agreed to talk).
- Keep respondents **anonymous** unless they are a named public figure speaking in that
  capacity (e.g. the policy expert).

## How to file a transcript

- **One Markdown file per session.** Suggested names:
  - Intercepts: `intercept_2026-06-19_SUD-N-03_01.md`
  - Expert interview: `interview_expert_YYYY-MM-DD.md`
- Header each file with: date, location/segment, interviewer(s), consent status
  (participate ✓ / record ✓ or ✗), and language.

## Template

```markdown
# <Intercept / Interview>: <date>

- Location/segment:
- Interviewer(s):
- Consent: participate ☐  record ☐
- Language:

## Transcript
Q: …
A: …
```

> Transcribe faithfully. Keep your interpretation out of the transcript itself, analysis
> happens later in synthesis, from the real words.
