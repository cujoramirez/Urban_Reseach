# Field Research Prep Checklist

Everything to prepare, get, and bring before fieldwork (Wed 17 / Thu 18 / Fri 19 June).
Pairs with [`observation-protocol.md`](observation-protocol.md),
[`fieldworker-presentation.md`](fieldworker-presentation.md),
[`data-sources-and-methods.md`](data-sources-and-methods.md), and the
[`instruments/`](instruments/) sheets. Print this and tick as you go.

---

## A. Prepare / get ahead of time (desk, H-1 or earlier)
- [ ] **Academy intro letter** requested H-1 (carry a copy every field day).
- [ ] **Anies / Karsa / UDK** expert-interview proposal sent; slot pending ADA confirmation.
- [ ] **Pick the segments:** list the named-street pairs (each main-corridor block + its
      back-street block) and the three nodes (Dukuh Atas/Stasiun Sudirman, GBK--FX, Ratu
      Plaza/Menara Mandiri). Mark them on a shared map.
- [ ] **Offline maps** of the segments downloaded (Apple Maps / Google Maps offline area).
- [ ] **WeatherKit logging** tested on at least one phone (records temp, apparent temp,
      humidity, precip probability, UV per timestamp). Decide who logs each window.
- [ ] **Street View + aerial tiles** for the segments pulled at the desk (for the CV pipeline,
      so the field team is not blocked).
- [ ] **OSM check** of building footprints/heights for the shade layer (desk task).
- [ ] **Print instruments** (see section C) and pre-fill segment IDs.
- [ ] **Charge everything** the night before; format/clear phone storage for photos/clips.
- [ ] **Weather look-ahead** for the field days; plan window order around heat and rain.
- [ ] **Sensing-walk kit** assembled and tested (section B).

## B. Shared kit to bring
- [ ] **Printed instruments** (audit sheets, tally sheets, intercept script, interview guide,
      perception-scale cards), several copies each, on a clipboard.
- [ ] **Pens** (a few spare) + a couple of **markers**.
- [ ] **Tape measure or laser distance meter** (to measure effective sidewalk width against the
      **1,85 m** standard; do not eyeball it).
- [ ] **Phones** with: counts CSV/spreadsheet, camera, WeatherKit, stopwatch/timer, GPS, offline map.
- [ ] **Power banks** + cables (a full day of GPS/camera drains batteries fast).
- [ ] **Sensing-walk logger** (temperature/humidity/lux + GPS), charged, time-synced.
- [ ] **Water** (each person) + **umbrella** (sun and rain; you are also testing umbrella use).
- [ ] **Hat / light layer / rain layer**; comfortable closed shoes.
- [ ] **Consent cards** (printed consent line, ID for who to contact).
- [ ] **Academy ID / lanyard**, intro letter copy.
- [ ] **Cash / e-wallet** (warung, parking, ojol if needed for node coverage).
- [ ] **Small first-aid** (plasters, hand sanitizer).

## C. Print pack (instruments)
- [ ] Audit sheet (`instruments/audit-sheet.md`) -- 2 per segment pair, IDs pre-filled.
- [ ] Observation tally sheet (`instruments/observation-tally-sheet.md`) -- per segment/window.
- [ ] Intercept script (`instruments/intercept-script.md`) -- consent line visible.
- [ ] Interview guide (`instruments/interview-guide.md`) + bank for reference.
- [ ] Perception-scale cards (ASHRAE 7-point, safety/comfort scale).

## D. Digital setup (agree before you go)
- [ ] **Counts file:** shared CSV with the header in `field/data/README.md`; one row per window.
- [ ] **Photo naming:** `SEGMENTID_YYYY-MM-DD_NN.jpg`; blur faces; note GPS.
- [ ] **WeatherKit capture:** who logs, every window; record the reading with the segment ID.
- [ ] **Clock sync:** all phones on the same time so counts, photos, weather, and sensor align.
- [ ] **Backup plan:** end-of-day upload of sheets (photographed), CSVs, photos, sensor logs to
      shared storage; do NOT commit large raw media to git (see `photos/README.md`).

## F. Safety (non-negotiable)
- [ ] **Buddy system** off the main trotoar; share live location with the team.
- [ ] **Back-streets in daylight first**; greet RT/RW before observing/asking.
- [ ] **Night/sensitive intercepts led by Sintani**, never solo.
- [ ] Emergency contacts saved; agree a meet-up point and a check-in time.
- [ ] Disengage politely if any interaction feels unsafe, for you or the respondent.

## G. End of day
- [ ] Photograph/scan all paper sheets; back up CSVs, photos, sensor logs.
- [ ] Quick debrief: surprises, gaps, what to adjust tomorrow (keep it neutral; no conclusions).
- [ ] Recharge kit; re-stock printed sheets for the next day.
