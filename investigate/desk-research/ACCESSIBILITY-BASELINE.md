# Accessibility Baseline (standards reference for the Act-stage pivot)

> **Purpose.** The standards baseline for the accessibility pivot (Persona 4; the
> [place-accessibility audit](../field/instruments/place-accessibility-audit.md)). It answers the
> mentor's question — *"is there a standard?"* — with **yes**, and names which one binds. Every
> figure traces to a source note (S25–S29 + S13); see those for exact quotes.
>
> **Discipline:** this is a *desk-research baseline*, not a finding about Sudirman. It tells us what
> "accessible" should mean; the field audit tells us whether places meet it.

## Which standard is the baseline (hierarchy)
1. **Binding (Indonesia):** **Permen PUPR 14/2017** ([S29](notes/S29-permenpupr-14-2017-kemudahan-bangunan.md),
   buildings/approach) + **Bina Marga 07/2023** ([S13](notes/S13-binamarga-2023-pedoman-pejalan-kaki.md),
   pedestrian facilities). The enforceable yardstick.
2. **International reference (where local specs are silent, or for cross-check):**
   **ISO 21542:2021** ([S25](notes/S25-iso-21542-2021-accessibility.md)) and the freely-dimensioned
   **2010 ADA Standards** ([S26](notes/S26-ada-2010-standards.md)).
3. **Rights & philosophy frame (the "why"):** **UN CRPD Art. 9**
   ([S27](notes/S27-uncrpd-2006-article9.md); Indonesia bound via UU 19/2011 + UU 8/2016) and the
   **7 Principles of Universal Design** ([S28](notes/S28-universal-design-7-principles.md)).

**Scoring rule.** Where local and international specs differ, score against the **stricter** value
for user safety, and record the measured value. Use a **graded verdict** (accessible / partial / not)
— consistent with ISO 21542's "exceptional considerations for existing buildings" (most Jakarta
places are retrofits, not new builds).

## Consolidated dimensional baseline (the audit's benchmarks)

| Element | Binding (Indonesia) | International ref | Audit criterion (use stricter) | Source |
|---|---|---|---|---|
| **Ramp slope** | ≤6° ≈1:10 indoor / ≤5° ≈1:12 outdoor (PUPR); ≤8% =1:12 (Bina Marga) | ≤1:12 (ADA) | **≤1:12 (~4.8°)**; 1:12–1:8 = partial; steeper/none = fail | S29, S13, S26 |
| **Ramp width** | ≥95 cm (≥120 cm w/ curb) (PUPR) | ≥915 mm (ADA) | **≥120 cm** | S29, S26 |
| **Ramp landing** | every ≤900 cm of run (PUPR) | ≥1525 mm long (ADA) | landing present; ≥150 cm long | S29, S26 |
| **Safety curb (kanstin)** | ≥10 cm (PUPR) | — | present, ≥10 cm | S29 |
| **Door clear width** | accessible door required (PUPR) | ≥815 mm (ADA) | **≥90 cm** clear | S26, S29 |
| **Circulation / path width** | sidewalk ≥185 cm (Bina Marga) | ≥1525 mm turning (ADA) | **≥120 cm** to pass / ~150 cm to turn | S13, S26 |
| **Accessible toilet** | required: grab bars + turning space (PUPR) | grab bars + clear floor (ADA) | present + grab bars + ~150 cm turn + door ≥90 cm | S29, S26 |
| **Tactile / guiding block** | ubin pemandu required (PUPR) | detectable warnings (ADA) | continuous + unobstructed | S29 |
| **Sidewalk width (approach)** | ≥1,85 m (Bina Marga) | — | **≥1,85 m** | S13 |
| **Crossing spacing** | 100–200 m (Bina Marga) | — | **≤200 m** | S13 |
| **Seating / rest** | not regulated | — | benches frequent (~200 m, *field-grounded* benchmark) | field (Kak Ica) |

## How the baseline is used
- It standard-references the
  [place-accessibility audit](../field/instruments/place-accessibility-audit.md): each 0–2 score is
  keyed to a threshold above. It also extends the spatial schema
  ([`../spatial/SCHEMA.md`](../spatial/SCHEMA.md)).
- It makes the app's "accessible / partial / not" verdict **defensible** — a cited standard behind
  every claim, which is exactly what the mentor pushed on.
- The **rights frame (S27)** + **Universal Design (S28)** justify the product's independence goal and
  the curb-cut logic (design for permanent disability → benefits temporary, situational, and lansia).

## Flags / open items
- Toilet & lift exact dimensions sit in the PUPR Lampiran figures (S29 flag) — pull before final reporting.
- ISO 21542 dimensional clauses are paywalled (S25) — ADA (S26) substitutes for the numbers.
- Seating spacing has **no** regulatory figure; the ~200 m benchmark is field-grounded (Kak Ica),
  not a standard — always label it as such, never as a code requirement.
